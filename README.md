## The entry

> Sticky Note, c. 2021. The owner's bank password, written on paper and stuck to the monitor it unlocked, for security.

A museum label from the year 3000, placed beside an ordinary object from today — a sticky note carrying its owner's bank password, stuck to the very monitor it unlocked.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library, needs no network, and is deterministic: it always writes the same single line (117 characters, no trailing newline) to `/output/entry.txt`.
